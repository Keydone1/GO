# Users API

Краткое описание: REST API для управления пользователями.

Базовый URL: http://localhost:8080
Формат данных: JSON (UTF-8)

---

## Модель User

| Поле  | Тип    | Описание |
|-------|--------|----------|
| id    | int64  | Уникальный идентификатор |
| name  | string | Имя (1..100 символов) |
| email | string | Email (уникальный) |
| age   | int    | Возраст (0..150) |

Пример:
```json
{"id": 1, "name": "Alice", "email": "a@x.com", "age": 30}
